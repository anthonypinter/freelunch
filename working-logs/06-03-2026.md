### 2. Smart Sign In Button on `index.html`

**Problem:** The "Sign In" nav button always showed even when the user was already logged in.

**Fix:** The same inline module script added for the admin link also handles this. After `getSession()` resolves:
- If a session exists → changes the button's `href` to `profile.html` and label to `"My Profile"`
- If no session → button stays as "Sign In" → `login.html` (no change)

**File changed:** `index.html` — added `id="signin-nav-btn"` to the nav Sign In link, added `<script type="module">` at bottom of body.

### 3. Clickable Logo on `dashboard.html`

**Problem:** The site name logo in the dashboard header was a plain `<div>` with no link.

**Fix:** Changed `<div class="header-logo">` → `<a href="index.html" class="header-logo">`.

Added to `css/style.css` on `.header-logo`:
```css
text-decoration: none;
color: inherit;
```
So the anchor inherits the white header color and has no underline.

**Files changed:** `dashboard.html`, `css/style.css`

### 4. Dashboard Carousel Caption Polish

**Problem:** The description, "what you had to do to get it" text, and user info row were cramped with no visual separation, and all text was hard to read over bright photos.

**Root cause:** `.carousel-how` had no CSS at all (missing entirely). The gradient scrim was too short and too light. No text-shadow anywhere.

**Fixes in `css/style.css`:**

- **Stronger gradient scrim** — `linear-gradient(transparent, rgba(0,0,0,.5) 25%, rgba(0,0,0,.88))` — now starts dimming at 25% and reaches near-black at the bottom
- **More caption padding** — top padding increased from `2.5rem` to `4rem` so the scrim reaches higher and text never feels cut off
- **`.carousel-desc`** — added `text-shadow: 0 1px 6px rgba(0,0,0,.6)`, bumped font-weight to 700
- **`.carousel-how`** (new) — `font-size: .9rem`, `font-weight: 500`, `margin-bottom: .9rem`, `text-shadow`, `-webkit-line-clamp: 2`
- **Separator before user row** — added `border-top: 1px solid rgba(255,255,255,.2)` and `padding-top: .75rem` to `.carousel-user` to cleanly divide submission text from submitter info
- **`.user-name` / `.user-handle`** — added `text-shadow` to both for contrast against bright photos
